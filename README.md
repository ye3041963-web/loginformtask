# Login Form Task

A simple login form built with Java AWT.

## Features
- Validates empty fields
- Checks that the user exists
- Checks the password and the selected role
- Shows an error message for invalid input
- Disables the Login button after 3 failed attempts (bonus)
- Opens a welcome page showing the username and role
